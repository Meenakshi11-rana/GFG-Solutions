# [Lowercase to Uppercase](https://www.geeksforgeeks.org/problems/lower-case-to-upper-case3410/1)
## Easy
Given a string s containing only lowercase English letters, convert all its characters to uppercase and return the resulting string.Examples:Input: s = "geeks"
Output: GEEKSExplanation: All lowercase characters are converted to their corresponding uppercase characters.Input: s = "geeksforgeeks"
Output: GEEKSFORGEEKSExplanation: Each lowercase character in the string is converted to uppercase.
