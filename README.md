# GFG & LeetCode Solutions

A curated collection of solutions to Data Structures and Algorithms (DSA) problems solved on **GeeksforGeeks** and **LeetCode**, implemented primarily in Java and Python.

## 📌 Features

- **Automated Tracking:** Integrates with extensions like LeetHub to automatically push problem solutions and performance metrics.
- **Complexity Analysis:** Solutions include Time and Space complexity details in the commit history or code headers.
- **Language Stack:**
  - **Java** (Primary)
  - **Python**

## 📂 Repository Structure

The problems are organized into folders named after their corresponding problem ID and title:

```text
├── 0020-valid-parentheses/
├── 0026-remove-duplicates-from-sorted-array/
├── 0048-rotate-image/
└── ...
Each problem folder typically contains:

The problem description / instructions.

The source code file with the optimal solution.
